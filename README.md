# rest-eeg-network-reliability
Codes to compute network measures from resting-state EEG signals and to conduct reliability analysis.

This repository is an extension of a conference paper accepted EMBC 2025: 

Matthew King-Hang Ma, Manson Cheuk-Man Fong, William Shiyuan Wang (2025). A Reliability Study in Resting-state EEG Network Characteristics: Frequency of Interest, Number of Oscillatory Cycles and Thresholding.
